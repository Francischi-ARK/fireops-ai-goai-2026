# FireOps AI｜工业消防闭环 Agent

FireOps AI 面向工厂、仓库、学校、医院和商业综合体的消防管理场景，把报警、应急处置、设施维保、防火巡查和战评放进一条可追溯的任务链。

**在线演示：** [打开 FireOps AI](https://francischi-ark.github.io/fireops-ai-goai-2026/#/home)

公开版无需后端即可运行。点击右上角“评委模式”，可依次体验：

1. 真实火警：报警接入 → 人工核实 → 调派 → 到场反馈 → 对讲指挥 → 归档与战评。
2. 误报转维保：误报确认 → 故障工单 → 维保处理 → 设施部门验收。
3. 巡查整改：图片与口述 → 隐患草稿 → 人工派发 → 上传整改照片 → 巡查复查。

## 数据与安全边界

- 页面中的企业、人员、点位、事件和指标均为合成演示数据。
- 真实企业 Excel、原始业务记录、账号、密钥、测试录音和 BIM 源文件未进入公开仓库。
- Agent 负责理解信息、检索证据、识别缺项和生成草稿；确认火情、派单、启动设备、验收和归档仍由授权人员决定。
- 系统不上控，不自动启动消防设备，也不自动拨打 119。
